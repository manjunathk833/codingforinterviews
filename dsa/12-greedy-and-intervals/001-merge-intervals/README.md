# 001. Merge Intervals

- **Difficulty**: Medium
- **Pattern**: Greedy & Intervals
- **LeetCode Link**: [LeetCode #56 - Merge Intervals](https://leetcode.com/problems/merge-intervals/)

---

## Problem Statement
Given an array of `intervals` where `intervals[i] = [start_i, end_i]`, merge all overlapping intervals, and return *an array of the non-overlapping intervals that cover all the intervals in the input*.

---

## Target Complexities
- **Optimal Time Complexity**: $O(N \log N)$ due to sorting
- **Optimal Space Complexity**: $O(N)$
